# Mental Health Survey - Exploratory Data Analysis

## 📌 Overview
This project analyzes a workplace mental health survey dataset to identify trends, correlations, and factors affecting employee mental health.

## 🚀 Features
- Data Cleaning & Handling Missing Values
- Exploratory Data Analysis (EDA)
- Data Visualization
- Correlation Analysis

## 🛠 Technologies Used
Python, Pandas, NumPy, Matplotlib, Seaborn

## 📊 Outcome
Identified key patterns and insights related to workplace mental health using data-driven analysis.
